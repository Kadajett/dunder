Install on Linux (x86_64)

curl -fsSL https://dunder.yougotserved.dev/install.sh | sh

Unattended? Add sh -s -- --yes. No sudo, and it asks before installing anything. Read the script first — we would.

Already on Node.js 22+?

npx dunder-ai@latest

Same setup, minus the Node.js check.

What it installs

Everything lives in your home directory. Pieces you already have are left alone; anything missing is installed only after you say yes.

app

Dunder

The desktop app as an AppImage in ~/.local/share/dunder, a dunder launcher in ~/.local/bin, and a desktop entry.

terminals

herdr

The terminal multiplexer the office runs on. Every agent works in a real pane of the office session.

agents

omp

The coding agent your staff are made of. Claude Code and Codex are welcome on the floor too.

memory

bd (beads)

A git-backed issue tracker the team uses for tasks and long-term memory.

if missing

Node.js

Only when you don't have 22 or newer: a private copy in ~/.local/share/dunder/node, checksum-verified against nodejs.org.

What happens when you run it

Five steps, nothing hidden, nothing installed without asking.

  1. Checks you're on Linux x86_64 and have Node.js 22+ (installing a private copy if not).
  2. Runs npx dunder-ai@latest setup, which checks for git, curl, herdr, omp and bd.
  3. Shows you the plan and asks before installing anything that's missing.
  4. Downloads the latest Dunder release, verifies it, and adds the launcher.
  5. Run dunder. Your first hires are already waiting at reception.
